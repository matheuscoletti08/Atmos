# [Atmos](https://matheuscoletti08.github.io/Atmos/)

Uma aplicação de clima minimalista desenvolvida com HTML, CSS e JavaScript puro.

## Sobre

O Atmos é uma aplicação simples para consulta de clima, criada com foco em uma interface limpa e no aprendizado dos fundamentos de consumo de APIs com JavaScript.

A aplicação permite pesquisar por uma cidade e visualizar a temperatura atual, sensação térmica e condição climática.

## Funcionalidades

- Pesquisa por cidade
- Temperatura atual
- Sensação térmica
- Condição climática
- Estado de carregamento
- Interface responsiva
- Pesquisa pressionando Enter
- Atualização dinâmica da interface

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Open-Meteo API

## API

O Atmos utiliza a Open-Meteo para obter os dados de localização e clima.

Primeiro, a aplicação pesquisa a cidade e obtém suas coordenadas. Em seguida, utiliza latitude e longitude para consultar as condições climáticas atuais.
